# Mouse vs Snakes Game 🐭🐍

A simple **Python game** built with `pygame` where you control a mouse trying to survive against chasing snakes!  

---

## 🎮 How to Play

- Use the **arrow keys** to move the yellow mouse:
  - `↑` → Move up  
  - `↓` → Move down  
  - `←` → Move left  
  - `→` → Move right
- Avoid the **red snakes**. If a snake touches the mouse, the game ends.  
- Over time:
  - The mouse **gets faster** every 5 seconds.  
  - Snakes **multiply** every 4 seconds to make the game more challenging.  

---

## ⏱ Features

- Real-time movement with arrow keys  
- Increasing difficulty: faster mouse and multiplying snakes  
- Timer shows how long you survive  
- Simple UI messages for speed boosts and snake multiplication  

---

- `pygame` library
